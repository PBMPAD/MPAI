# Design rules (all client sites and demos)

Set by Matthew Price, MPAI, 20/11/26. Follow these on every client site and demo.

## Before designing
- Run `/impeccable init` if PRODUCT.md and DESIGN.md don't exist. Fill in the anti-references with the banned list below.
- Ask Matthew for 2 or 3 reference sites, or the client's existing brand. Don't start without one. (Per client: HBL Homes uses Stow Brothers, stowbrothers.com, as its only reference.)
- Use the client's own words for headlines and taglines, taken from their website, emails or call transcripts. Never invent a tagline. If there isn't one, leave a clearly marked placeholder.

## Banned unless the client's brand already uses it
- Text shadows and glows
- Decorative borders, double frames, inset hairlines
- Scalloped, wavy or zigzag edges, awnings, ribbons
- Gold or brass accents on dark teal, navy or green
- Cards floating over the hero image
- Caption pills on photos
- More than one accent colour
- More than two typefaces
- Full stops after every short headline fragment

## Defaults
- Let the photography lead. Light background, plain type, generous space.
- Set headlines at a calm size. Hierarchy comes from spacing and weight, not effects.
- Plain English copy for business owners.
- Never caption a hero photo or say which home or property it was taken from.

## Before showing Matthew anything
1. Run `/impeccable critique` and fix what it finds.
2. Screenshot the page at mobile width and check it against the banned list.
3. Run the copy through the anti-ai-writing skill.
4. Tell Matthew in one line what you removed or changed.
