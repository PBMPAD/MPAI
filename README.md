# Putting the site live (about 20 minutes)

1. Create a free account at netlify.com.
2. In Netlify: Add new site, Deploy manually, then drag this whole folder onto the page. You get a test address straight away.
3. Forms: in the site's settings, open Forms, enable form detection, then redeploy (drag the folder again). Under Forms, Form notifications, add an email notification to your address.
4. Test it: fill in the form on the live site and check the email arrives.
5. Domain: once mpai.site is registered, add it under Domain management and follow Netlify's instructions to point the domain at the site. Keep the Microsoft 365 email records in place.

To change anything later, open the folder in Claude Code and ask, or edit and drag the folder onto Netlify again.
